# Citadel

Project workspace split into an application service, web client, and Arduino firmware.

## Structure

- `app/` — application service
- `webapp/` — browser interface
- `arduino/` — Arduino sketch and hardware notes

## Getting started

The folders are intentionally dependency-free starters so the repository can be opened and extended immediately.

```text
app/      npm run start
webapp/   npm run dev
arduino/  open citadel.ino in Arduino IDE
```

See each folder's README for details.
